# 高拍扫描助手

用于高拍仪的原生 macOS 应用，支持实时预览、连续自动对焦、手动拍照、自动检测文件和倒计时连拍。拍摄结果可自动编号，完整照片另存到「原片」文件夹。

应用支持自动裁切、手动框选、A4 比例锁定和自由圈选。自由圈选输出覆盖轮廓的最小矩形，圈外填白。手动拍照时可以将处理后的照片复制到剪贴板。

## 构建

需要 Apple 芯片的 Mac、macOS 14 或更新版本及 Xcode 命令行工具。

```sh
./build.sh
open "./高拍扫描助手.app"
```

首次运行时需允许摄像头访问。要使用光照补偿，请在应用中放入白纸校准。

主程序在 `Sources/`，USB 摄像头调节工具在 `UVCTool/`。图片增强辅助程序的 C 源码、构建使用的 ARM64 运行文件和第三方许可证在 `DocumentScan/`。
